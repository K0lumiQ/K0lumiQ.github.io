# Личный сайт: Владислав Ким

Личный сайт-портфолио full-stack разработчика: hero, обо мне, услуги, избранные проекты с живыми ссылками, процесс работы, контакты. Чистые HTML/CSS/JS, плавный скролл на Lenis (лежит локально, MIT). Язык русский.

- GitHub: https://github.com/K0lumiQ/K0lumiQ.github.io
- Опубликовано: https://k0lumiq.github.io/ (корневой сайт аккаунта)
- Макет: Figma «Aaronn (Copy)», шаблон портфолио дизайнера. Экспорт в `design/` (в репозиторий не попадает): Home Page (1440 px), Style Guide, логотип.
- Что взято из макета: структура страницы, тёмная тема `#1a1a1a`, оранжевый акцент `#ff9143`, карточки `#262a2c`, большие округлые кнопки, оранжевые контуры у фото, сетка проектов 2 колонки с подписями «Тип / Стек», крупная почта в контактах.
- Что изменено под владельца: имя, роль, тексты, контакты, 4 проекта вместо дизайнерских работ, блоки «Услуги» и «Как мы будем работать» (в макете их нет).

## Запуск

```
npx http-server -p 5176 -c-1 .
```

Открывать через сервер, не через `file://`.

## Где что менять

| Что | Где |
|---|---|
| Имя, почта, Telegram, GitHub | `ME` в `js/data.js` |
| Услуги, этапы работы, цифры, цитата | `SERVICES`, `STEPS`, `STATS`, `QUOTE` в `js/data.js` |
| **Проекты (новая карточка)** | массив `PROJECTS` в `js/data.js`: добавить объект, скриншот 1280×800 положить в `assets/img` |
| Категории фильтра | `FILTERS` в `data.js` и поле `type` у проектов |
| Текст «Обо мне» (абзац в hero-блоке) | `index.html`, секция `#about`; расширенный текст в окне: `ABOUT_MORE` в `data.js` |
| Цвета, скругления, шрифты | переменные в `:root` в начале `css/styles.css`, `css/fonts.css` |
| Анимации | `css/motion.css` и `js/fx.js` |

После последней карточки в сетке автоматически показывается заглушка «Ваш проект» (приглашение обсудить задачу). Если проектов станет нечётное число, она встанет на свободное место.

## Анимации (идеи и реализация)

Загрузчик с кольцом и шторкой, бегущая строка со стеком (скорость зависит от скорости скролла), окно проекта плавно вырастает из места нажатой карточки (без искажения картинки), построчное появление заголовков, плавное появление блоков и карточек каскадом, магнитные кнопки с заливкой волной, наклон карточек и подсветка под курсором, параллакс картинок проектов, кастомный курсор с подписями, индикатор активной секции в меню, полоса прогресса скролла, переходы смены фильтра, анимированные окна проектов, счётчики. Все анимации отключаются при `prefers-reduced-motion`, контент виден без JS.

## Заметки по окну проекта

Скриншот в окне показывается целиком в своей пропорции (без обрезки), на телефоне окно прокручивается, пока не виден блок кнопок. Окно растёт из центра нажатой карточки: смещение задаёт `app.js` через `--ox` и `--oy`, анимацию описывает `css/motion.css`.

## Структура

```
index.html         страница
css/styles.css     вёрстка и цвета (токены в :root)
css/motion.css     все анимации и состояния появления
css/fonts.css      локальные шрифты Unbounded и Rubik
js/data.js         данные: контакты, услуги, проекты
js/app.js          отрисовка карточек, фильтр, окна, форма
js/fx.js           плавный скролл, появление, курсор, магниты
assets/js/         Lenis (плавный скролл)
assets/img/        скриншоты проектов
design/            макет (только локально)
```

## Заметки

- Шрифт макета Syne не поддерживает кириллицу, поэтому заголовки набраны Unbounded (похожий широкий геометрический шрифт), текст Rubik как в макете.
- Форма контактов открывает почтовый клиент с готовым письмом (`mailto:`): без сервера письма сайт не отправляет.
- Карточки проектов ведут на живые сайты (GitHub Pages) и репозитории.
